📖 使用说明

快速上手

1. 打开工具

  1. 点击「立即打开工具」，或直接访问 https://chanzuiyv.github.io/weibo/（推荐 Chrome / Edge，手机浏览器也可用）。
  2. 建议把网址收藏/添加到主屏幕，方便下次打开。

2. 注册与登录

  1. 首次打开需阅读并同意「风险告知书」（必须确认才能进入）。
  2. 点击「注册」创建账号（账号密码仅存在你本地浏览器，不上传）。
  3. 登录后可新建艺人目录，选择年份进入工作区。

3. 添加微博

  1. 「②微博整理」→「添加微博」，手动填写文案、上传图片/视频。
  2. 或用「只存链接」模式：粘贴微博链接，自动检测存活并抓取正文/图片（需配置通道）。

4. 配置自动检测通道（可选）

三选一，在工具「④设置 → 外链与检测通道」中配置：

  • 油猴脚本（推荐）：装 Tampermonkey 扩展 + 一键安装脚本，无需 Python，电脑端全自动。
  • Cloudflare Worker：部署一次，手机也能全自动（工具设置页可一键复制代码）。
  • 本地代理：装 Python 后双击启动器，填 http://127.0.0.1:8787。
⚠️ 数据安全提醒：数据存储在你本地浏览器中。清除浏览器数据会丢失所有内容，建议定期使用「导出数据」功能备份。工具不会上传任何数据到服务器。
