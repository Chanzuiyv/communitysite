🎨 头像框投稿

设计你的专属头像框，让所有用户都用上你的作品

📦 投稿是什么？

工具内「个人中心 → 头像框」提供 10 款系统默认头像框（彩虹、极光、落日、翡翠、金辉、冰蓝、暗夜、樱花、极简白、极简黑）。本通道接受社区原创投稿，票数高的作品经开发者审核后会被入库成为官方头像框，全站所有用户都能在「头像框」选择页里选用。

📐 文件要求（三选一）

① 渐变 / 纯色（最简单 · 文字投稿即可）

  • 提交一句 CSS background 表达式
  • 例： linear-gradient(135deg,#667eea,#764ba2) 或 #ff6b9d 或 repeating-linear-gradient(45deg,#f0f0f0,#f0f0f0 10px,#e0e0e0 10px,#e0e0e0 20px)
  • 仅接受 linear-gradient / radial-gradient / repeating-*-gradient / #hex / rgba() 等纯色或渐变表达式

② 图案 PNG（推荐 · 能做装饰性头像框）

  • 尺寸：220×220px（2 倍图，保证高清）
  • 格式：PNG（必须支持 alpha 透明通道）
  • 中央透明：直径 ≥ 208px 的圆形必须保持完全透明，不得遮挡头像
  • 外圈装饰：装饰宽度建议 3–10px，圆环形态，不得是方形
  • 角外透明：圆环以外区域必须完全透明（不要铺底色）
  • 文件大小：≤ 200KB
  • 命名：frame-英文ID.png（如 frame-sakura.png）
  • 主题参考：花朵环绕、星点装饰、彩带、节庆元素、几何纹理等

③ SVG 矢量图（专业投稿）

  • 单文件 SVG，viewBox="0 0 220 220"
  • 中央保持透明圆形（直径 ≥ 208px）
  • 不得内嵌光栅图片 / 字体 / 外链资源
  • 文件大小：≤ 100KB
  • 命名：frame-英文ID.svg

✏️ 内容规范（必须遵守）

  • 须为原创，不得抄袭、搬运他人作品
  • 不得含有：违法违规内容、艺人照片、明星肖像、品牌 logo、二维码、广告、外链
  • 不得含有：可能引起争议的政治、宗教、歧视性符号
  • 不得含有：恶意代码 / 脚本 / 数据 URI 形式的可执行内容

📨 投稿方式

  • 方式一（推荐）：到下方「💬 留言区」→「优化建议」分区发帖，附文字描述或图片文件，标题前缀写「头像框投稿」
  • 方式二：私发邮件至 2720115869@qq.com，主题格式：头像框投稿-作品名-作者昵称
  • 作者昵称可选填，不填则默认匿名

📤 投稿上传指南

留言区评论框已支持图片上传（PNG / JPG / GIF / WebP），按下方说明操作即可。SVG 文件请用网盘方式（见文末）。

📷 图片投稿（直接传到评论区）

  1. 在评论区输入框下方找到「图片」按钮（评论框右下角工具栏）
  2. 点「图片」→ 选本地 PNG/JPG/WebP 文件 → 等待自动上传
  3. 上传成功后图片会自动插入到评论正文
  4. 补充文字描述（如「作品名：xxx，作者：xxx」）→ 发布
⚠️ 单图大小 ≤ 5MB。评论区仅支持图片格式，不支持 SVG / 任意文件，请看下方「文件投稿」。

📎 文件投稿（PNG / SVG / 备用方案）

留言区评论框不支持任意文件上传，请用以下任一方式传文件，然后把分享链接贴到评论正文：

  • 蓝奏云（推荐，国内速度快）：https://www.lanzoui.com/ 上传 100MB 以内文件，得到分享链接
  • 奶牛快传：https://cowtransfer.com/ 7 天有效
  • 腾讯微云 / 百度网盘：永久存储但提取码较繁琐
  • GitHub Gist（适合 SVG 代码）：https://gist.github.com/ 贴 SVG 源码即可
💡 示例：评论文案写「头像框投稿-樱花环-小橘子」，正文贴：蓝奏云下载：https://xxx.lanzoui.com/xxx 提取码:1234

🏆 评选流程

  1. 每周汇总一次投稿，候选作品在公告栏置顶公示
  2. 用户在「优化建议」分区对候选作品回复表态（👍 / 💬 评论）
  3. 得票高 + 合规的作品由开发者审核入库
  4. 下一版本工具更新时上线，所有用户在「头像框」选择页即可选用
  5. 入选作品会显示「作者：<昵称>」标签（作者可署名）

📋 投稿即同意

  • 提交即视为原创承诺，如有侵权由投稿者自行负责
  • 投稿作品一经入库，开发者保留最终上架 / 下架 / 微调（如压缩体积）的权利
  • 投稿作品不向投稿者支付费用，为社区共建无偿贡献
💡 小提示：第一次投稿建议先做简单渐变式试水（方式 ①），熟悉规范后再做图案 / SVG 复杂头像框。如有疑问，到「优化建议」分区提问即可。

📖 使用说明

快速上手

🚀 快速上手（三步）

  1. 打开工具 → https://chanzuiyv.github.io/weibo/（或点上面的「立即打开工具」）。电脑端、手机浏览器都支持，建议收藏网址或添加到主屏幕。
  2. 注册登录 → 首次需同意风险告知书（必须确认），账号密码仅存在你本地浏览器，不上传任何服务器。
  3. 新建艺人 / 选年份 → 进入工作区开始添加微博。

📱 手机端 vs 💻 电脑端

两种界面风格，可在工具顶部点击切换按钮自由选择：

  • 自动（推荐）：≤768px 屏幕自动手机端，>768px 自动电脑端
  • 强制电脑端：窄屏也显示左侧竖排侧边栏，适合大屏手机横屏操作
  • 强制手机端：始终显示底部 Tab 栏

✍️ 添加微博

  • 手动添加：填文案、上传图片/视频，最稳妥可靠。
  • 只存链接（自动抓取）：粘贴微博链接即可自动检测存活、抓取正文、提取图片视频。已默认集成腾讯云 SCF 代理，无需额外配置通道即可使用。

🖼 图片 & 🎬 视频预览

  • 手机端每张微博卡片显示：1 张图片缩略图 + 1 个视频缩略图（并排同行）
  • 图片右下角「共 N 张」角标 → 点图片 全屏大图浏览，可左右滑动看全部
  • 视频有独立的 ▶️ 播放键 + ⛶ 全屏键，全屏退出后自动回到原浏览位置

⭐ 收藏夹 / ❤️ 点赞 / 🏷️ 标签

  • 电脑端：在「⑤个人中心」顶部 Tab 切换
  • 手机端：个人中心顶部有 「⭐ 收藏」「👤 账号」 两层级切换，收藏夹/点赞/标签在「⭐ 收藏」里作为内层 Tab 管理
  • 手机端收藏夹展开区自动隐藏第二套操作按钮，保持界面干净

🔄 整库备份 & 换机恢复

数据存在你本地浏览器 IndexedDB 里，永不自动上传。换电脑 / 清理浏览器前务必做备份：

  • 整库备份（④账号页）→ 生成 .wbbak 文件，包含账号、艺人、微博、评论、图片、视频。手机端会弹提示告诉你下载到哪，并提供「📤 分享」按钮可存到云盘/微信/钉钉。
  • 换机恢复（④账号页）→ 选择之前备份的 .wbbak 文件，一键完整还原。手机端完全支持。
✅ 最稳的迁移路线：电脑上点「整库备份」→ 手机上点「换机恢复」选文件即可。

📦 旧版 Excel 数据迁移

v1.x 旧工具的数据文件夹（含成员名/年份目录 + weibo_data.json / 评论数据 Excel）：

  • 电脑端：④账号页点「选择旧版数据文件夹导入」，选父文件夹即可自动识别并合并
  • 手机端：手机浏览器 无法选文件夹（iOS Safari 不支持 webkitdirectory），请先用电脑端导入，再做整库备份→手机端恢复

🔗 代理通道（默认已配置）

自动抓取/失效检测功能依赖外链代理，v2.2 已默认集成腾讯云 SCF Web 函数代理 https://1492394154-3lg2zqjabe.ap-shanghai.tencentscf.com，覆盖 weibo.cn / weibo.com / t.cn 短链解析 / 视频转发 / 正文抓取，开箱即用无需配置。

如遇 SCF 代理不可用（极罕见），可改回油猴脚本或自行部署 Cloudflare Worker：

  • 油猴脚本（推荐，电脑端全自动）：装 Tampermonkey 扩展 + 一键安装脚本
  • 本地代理：装 Python 后双击启动器，填 http://127.0.0.1:8787
⚠️ 数据安全提醒：数据完全存储在你本地浏览器中，清除浏览器数据 / 卸载浏览器会丢失全部内容。请定期（每周至少一次）使用整库备份，备份文件请妥善保管、不要发给他人。工具 零联网，不上传任何数据。

❓ 常见问题

  • Q：手机上点视频全屏后怎么回到原位置？ A：v2.2 已修复，全屏退出后页面自动回到你之前滚动的位置。
  • Q：换了手机怎么把数据搬过去？ A：电脑上整库备份→传到新手机→换机恢复。手机也能备份但建议电脑操作更稳。
  • Q：手机上找不到旧版 Excel 迁移入口？ A：手机不支持选文件夹，请用电脑迁移后做整库备份。
  • Q：代理挂了怎么办？ A：默认 SCF 已替换掉之前不稳定的 Cloudflare Worker，腾讯云国内速度快且稳定。真挂了可以手动换油猴脚本或自己部署一份 SCF 代码。
